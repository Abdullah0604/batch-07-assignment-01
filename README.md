# Assignment Summary

এই assignment-এ আমি TypeScript এবং Markdown ব্যবহার করে কিছু blog post এবং problem solving করেছি।
solutions.ts file এ basic problem গুলো solve করার চেষ্টা করেছি। সেই সাথে blog-1.md file এ type `any` এবং type `unkown` সম্পর্কে বিস্তারিত লিখেছি। তাছাড়া, blog-2.md file এ generics type সম্পর্কে আলোচনা করেছি।

## এই assignment থেকে আমি শিখেছি:

- TypeScript-এর type system কীভাবে কাজ করে
- কেন `any` avoid করে `unknown` use করা উচিত
- Generics কীভাবে code কে reusable এবং safe করে
- কিভাবে markdown file structure এবং maintain করতে হয়
